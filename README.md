# AI Engineering Portfolio Web App

An interactive, responsive single-page web application designed to showcase enterprise AI architectures, agentic workflow simulations, system design diagrams, and cloud microservice stacks.

---

## Features

- **Interactive AI Workflow Visualizer**: Multi-step pipeline simulation with live console logging.
- **Modern Responsive UI**: Built with Bootstrap 5 and custom glassmorphism styling.
- **Light & Dark Theme**: Dynamic theme switching with persistent user preference.
- **Architecture & System Visualizers**: Interactive cloud architecture diagrams and execution flows.
- **Single-Page Experience**: Smooth anchor-based navigation with mobile drawer support.

---

## Getting Started

### Prerequisites

Ensure you have the following installed on your system:
- **Node.js** (v18.x or higher recommended)
- **npm** (v9.x or higher)

### Installation

Clone the repository and install dependencies:

```bash
npm install
```

### Development

Start the local development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

The application will be accessible at `http://localhost:3000`.

### Production Build

Create an optimized production build in the `dist/` directory:

```bash
npm run build
```

### Preview Build

Preview the production build locally:

```bash
npm run preview
```

### Deployment

Deploy the `dist/` directory to GitHub Pages:

```bash
npm run deploy
```
